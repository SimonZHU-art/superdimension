# 素材与来源记录

本轮没有下载、嵌入或复制商业游戏的地图、人物、建筑、音乐或音效。

| 内容 | 来源 | 使用说明 |
|---|---|---|
| 岛屿轮廓、草地、建筑、树林、居民、猫与昼夜气氛 | `src/worldData.js`、`src/World.jsx` 中本轮原创 Canvas 绘制 | 以有限色块与像素轮廓编写，不依赖外部游戏素材 |
| 面板图标、人物头像 | `src/Icons.jsx` 中本轮原创 SVG／像素图形 | 与世界角色共享颜色，保留可访问的 HTML 文字说明 |
| 海风与交互声 | 客户端 Web Audio 程序合成 | 用户交互后启动，静音／音量由用户控制；没有录音版权素材 |
| 生活短故事、居民姓名与对白 | `src/content.js` 中本轮原创内容 | 虚构剧情仅属于游戏，不作为真人档案或模型事实来源 |
| 岛主公开介绍 | 项目既有公开个人主页资料，经本次用户授权复用 | 正式验收仍需岛主复核公开事实及使用范围；私人资料和测试岛资料独立配置 |
| 测试资料与模型／邮件响应 | `tests/` 中明确标记的 TEST FIXTURE | 只用于工程测试，不进入产品默认汇报，不代表真实人物或真实服务成果 |
| 字体 | 用户设备上的中文系统字体 | 不分发字体文件；使用系统已有字体许可 |
| React、Vite 等依赖 | `package.json`／锁文件中的包 | 上游许可证与版本随包保留；构建时使用其原许可证 |

《星露谷物语》仅为温馨生活与空间情绪参考；本轮城邑、角色与剧情均独立制作。后续新增图片、音频或作品附件时，应在此记录实际作者、来源链接和允许的使用范围。

2026-10-06 新增 BGM《灯下的小径》：本项目原创旋律与程序配器，源文件 `src/townMusic.js`，无第三方录音或采样。四处路灯、木料、花架、小怪物与行业陈列台为本项目原创 Canvas 绘制。服装和教培文案、样例成果为本项目编写的预设示例，不是真实 AI 汇报。
