# 主会议室

右上角「我的岛屿」保留资料、过滤器、个性化、报告管理等书桌功能。地图的主会议室是独立的深度了解场景。

岛主入口：先显示木地板、窗户、会议桌与门口的房间，列出有效登记的来访记录。推荐依据当前资料版本的已完成报告，优先涉及岛主关注方向、有来源的相关项目以及居民给出的相关理由。页面展示推荐理由及方法，属于阅读次序建议，不声称真人意愿或合作决定。匿名到访仅统计数量。

选择来访者后，海关、档案官、策展人、研究员、联络官、漫游伙伴从门口依次入场，岛主与来访资料投影在桌边。角色有简单入场与交谈动画；海关介绍真实登记信息，四个工作居民轮流展示已保存报告，漫游伙伴仅提供明确标注的生活话语。没有完成的报告显示真实状态，不生成虚构分析。发言可暂停、手动选择、展开报告与原始来源，并前往档案馆或联络官继续联系。

游客入口：仅显示会议室画面与自己的邀请状态。寄出联系邮件并被岛主接受后，解锁普通会议室和自己的来访角色。私人推荐、其他访客目录、居民分析均不呈现；服务端私密接口要求岛主会话。

动画不表示对方实时在线。打开会议室、播放汇报和查看推荐不会新增模型调用或自动发送邮件。系统尊重减少动态效果设置，关闭入场与交谈动画，并默认暂停轮播。
