# v0.18 刷新从游客序章开始

2026-10-10。正式主岛 8787 与快速造船试玩岛 8792 共用本轮入口补丁。

每次打开或刷新普通小岛页面，都以游客视角在 17:00 的小船上开始。阿斯伽德重新走来迎接，序章对白从第一句开始；即使上一次已经登录岛主，或正在跟随居民去主宅，也不会自动跳到岛主、旧房间、夜雾或远航界面。

已有岛主认证不会被撤销，但本次进入仍需通过菜单手动登录，才接管朱珠。确认登录后，可以恢复原有正式聚会、本地远航或开发隔离会话。主题聚会邀请链接保留专用邀请入口，不用普通主岛序章覆盖邀请窗口。

本轮重置的是序章的出生位置、临时对白和当前角色呈现。访客登记、资料、任务、收藏、摆放、物资、船和当天奖励账本保留；不在每次刷新时重复创建来访记录或发奖励。原游客已完成序章时，其时间、夜晚、位置及可访问房间暂存，重走序章完成后按原逻辑接回；尚未完成的首轮序章从头开始，完成后进入黄昏。当天任务与物件在序章画面中隐藏，实际进度暂停保留。
