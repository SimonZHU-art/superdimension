# 本地启动、配置与验收

这是独立于仓库旧个人主页的 `superdimension` 应用。运行时需要 Node.js 24 或更新版本（使用内置 `node:sqlite`）与 npm。开发阶段使用本地 SQLite 与常驻服务端任务；关闭浏览器不会关闭后台处理，停止服务端进程会暂停任务，重新启动会恢复尚未完成的工作。

## 本地启动

在项目目录执行：

```sh
cd .
npm install
cp -n .env.example .env
npm run dev
```

也可使用 `pnpm install --frozen-lockfile` 和 `pnpm dev`。请在本机配置 `.env`，并为 OWNER_PASSWORD 设置独立的强密码。

请确保 Node.js 24 或更新版本已加入 PATH。

桌面浏览器打开 `http://127.0.0.1:5174`。Vite 将 API、身份包与测试岛代理到 `127.0.0.1:8787`。此本地地址仅供本机浏览器使用；实际可分享链接需要部署。

```sh
npm test
npm run build
npm start
```

构建后服务端提供客户端与 API，默认打开 `http://127.0.0.1:8787`。测试使用随机端口、临时 SQLite、明确标记的模型／邮件测试夹具；不读取 `.env`，不发送真实邮件，也不消耗真实模型费用。

## 服务端配置

| 环境变量 | 用途 |
|---|---|
| `OWNER_PASSWORD` | 岛主登录密码，至少 12 字符；缺少时禁止岛主登录，没有默认密码 |
| `MODEL_PROVIDER` | `openai` 或 `deepseek`；只使用所选服务商，不自动切换 |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | DeepSeek 服务端密钥与模型，例如 `deepseek-flash` |
| `OPENAI_API_KEY` | OpenAI 服务端真实模型密钥 |
| `OPENAI_MODEL` | 账户实际可调用并支持 Responses 结构化输出的模型；不设置虚构默认模型 |
| `RESEND_API_KEY` | 服务端真实邮件服务密钥 |
| `MAIL_FROM` | 邮件平台已验证的发送身份，不伪装为访客邮箱 |
| `PUBLIC_BASE_URL` | 当前服务公开基地址，部署时填写实际 HTTPS 地址 |
| `DATA_PATH` | 持久化 SQLite 文件；默认 `server/data/island.sqlite` |
| `HOST` / `PORT` | 服务监听地址／端口；本地默认 `127.0.0.1:8787` |
| `QUEUE_INTERVAL_MS` | 后台队列检查间隔；仅自动测试设置为 `0` 后手动触发 |

密钥只放在服务端环境，不能使用 `VITE_` 前缀，也不能提交 `.env`、SQLite 或带真实资料的测试产物。模型服务和邮件服务缺少配置时，界面展示实际缺失原因；已有任务保留为可查看的失败状态，不生成占位汇报或假发送结果。

## 配置岛主与测试岛

在小镇“岛主入口”登录。分别填写公开身份、私人资料和过滤器；公开身份需要明确确认，私人资料与内部过滤偏好仅由服务端向获准任务提供。专项角色主题填写实际兴趣，未配置时应说明资料不足。

主岛身份包为 `/agent/profile.json`；简化测试岛页面为 `/test-island`，身份包为 `/test-island/agent/profile.json`。测试岛必须使用获准的真实资料并确认公开与处理许可后，才能作为真实身份互操作验收输入。开发占位身份或测试夹具不能替代这个环节。兼容外观为 `pixel-v1`，包含 `body`、`hair`、`skin`、`hat` 四个六位十六进制颜色。

当前资料入口支持粘贴文字及 TXT/MD；PDF 提取尚未接入，请先导出为文本。单次最多 3 份文件、资料合计 32,000 字符，交流补充后的会话资料合计最多 40,000 字符。客户端大小提示不能绕过服务端字符与请求体限制。

## 正确理解工作状态

登记后四个角色以固定输入版本与过滤版本工作，各自保存独立汇报及来源。修改过滤器不会覆盖历史成果。岛主可以重试失败角色，或在新配置下重新处理；相同输入／角色／过滤版本的成功成果不重复创建。纠正单独保留，不由模型悄悄覆盖。

联系路径为草稿、预览编辑、邮箱验证、明确确认、提交邮件服务。游客在邮箱收到验证代码，代码不会由 API 直接返回。邮件服务接受请求后保留其标识；这只表示服务商接收，入箱需要真实收件实测。待核实结果重试使用原始确认内容与同一请求标识，不能借重试修改已确认的邮件。[Resend 的幂等记录保留 24 小时](https://resend.com/docs/dashboard/emails/idempotency-keys)，超过安全重试窗口需核对服务商状态。

岛主在游戏内接受已发送联系后才能进入对应会议室。会议里的角色是本岛保存资料的投影；回答不是对方本人的即时回复或新承诺。删除访客会撤销后台工作并清理站内资料与派生成果，站内删除不能收回已经提交至外部邮件服务的内容。

## 部署与真实验收

当前提供代码与本地运行流程，没有创建生产部署或购买服务。部署时使用 HTTPS、实际 `PUBLIC_BASE_URL`、强密码与独立服务端环境；SQLite 所在目录必须持久化。这个版本为单进程服务，不能让多个 worker 共享同一任务队列并发发送。备份资料时将 SQLite 与 WAL 一并一致性备份，或停止进程后备份。

真实验收按 [ACCEPTANCE.md](./ACCEPTANCE.md) 执行：填写获准资料、接入真实模型和邮件服务、配置真实测试岛、记录事实错误与费用、确认真实邮箱收件。当前自动化测试只能证明接口边界与生命周期，不能证明真实模型语义准确性、个人化效果或邮件入箱。

## DeepSeek 配置

在 `.env` 设置 `MODEL_PROVIDER=deepseek`、`DEEPSEEK_API_KEY` 与 `DEEPSEEK_MODEL=deepseek-flash`，然后重启服务。使用官方 Chat Completions JSON 输出接口；服务器仍逐项检查结构与来源，不接受缺字段、错误引用或截断输出。输入／输出 Token 统一计入原有预算。余额不足不会自动重试。

接口说明：https://api-docs.deepseek.com/api/create-chat-completion/

## 岛屿个性化与密码

登录后进入「我的岛屿 → 岛屿个性化」，也可从齿轮设置中的「岛屿个性化与密码」进入。设置岛名、六位居民的名字和主角色衣服／发色／肤色／帽子颜色；这些外观名称可公开，真实身份姓名在「我的资料」单独管理。

最初密码由搭建工具随机生成，来自本机 `.env`。修改时输入当前密码和两次新密码（至少 12 字符）。新密码保存为 SQLite 中独立的 scrypt 校验值，不显示在配置 API，不以明文保存；其他岛主会话失效，当前会话更新。修改后以站内新密码为准，原 `.env` 初始密码不再用于登录。后端重启不恢复旧密码。暂无自助忘记密码恢复流程。
