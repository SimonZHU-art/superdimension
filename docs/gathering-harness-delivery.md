# v0.13 · 虚拟来客上岛与私人助理试玩

2026-10-10

## 现在怎么体验

打开 `http://localhost:8792/`，用试玩专用密码 `voyage-fixture-only` 登录岛主。从北岸船台进入「开发隔离」。这里先准备虚拟来客 B 的名字、介绍、项目、交流偏好与简历，再设置 B 每次聊天的固定回复。可以选择篮球岛或音乐岛，以及自己携带的助理功能。

点「与来客一起上岛」，操控的是自己的岛主角色。B 有名牌、持续行走的动画和可互动的身体；走近 B 按 E，或点击 B 后走近，发起交流。B 是否接受、是否开放资料，按准备窗口的测试选项执行。每条手动发出的消息收到同一条预设回复。

B 接受后，自己的助理立即处理 B 本次开放的资料。已提交聊天增量约每 30 秒合并一次；结束交流时结算最后一批。调度在服务端运行，切换标签页、动画暂停或离岛都不会取消已经接受的任务。自己的发现卡、建议问题、任务状态和测试档案均独立于 B 的收件箱。建议只追加到原草稿，由玩家检查后手动发送。

携带助理只携带功能。正常主题岛和测试主题岛都不再绘制随行助理的人物贴图。主岛上的故事居民仍保留。

## 配置与隔离

- TXT、MD 由浏览器读取；PDF、DOCX 在本机服务端提取正文。文件最多 2 MB、正文最多 14,000 字符；PDF 最多 20 页，扫描图片或加密文件会如实提示不能提取。
- 本机 PDF/DOCX 提取使用已有的 Python、pypdf、python-docx；部署到其他机器需提供相应运行时，可通过 `RESUME_PYTHON` 指定 Python。无解析器时可以粘贴正文或用 TXT/MD。
- 默认「模拟分析」从实际填写或上传的资料摘录，不调用收费模型，不伪装真人或模型已经完成深度判断。
- `npm run demo` 使用原配置中已有的 DeepSeek 模型变量开放「真实模型」选项。只有手动选中真实分析并开始有效交流后才调用模型。测试登录、邮件服务和 SQLite 均与正式岛分开；不沿用真实岛主密码，不注入正式库存，不发送真实邮件。
- 直接运行 `node scripts/voyage-demo.mjs` 时不加载模型配置；可以完全离线体验模拟分析。
- A 默认不开放自己的资料，只有勾选后才携带已经确认的公开介绍。私人关注方向仅供 A 的助理参考，不给 B。B 的资料开放和接受邀请也可关闭，验证拒绝、空资料和无助理分支。
- 试玩主岛现使用独立的 `.data/voyage-demo.sqlite`，不继承正式环境的 `DATA_PATH`。正式聚会入口的来客资料、库存、登录与档案在重启后保留；「开发隔离」工具里的模拟旅程仍只在该进程内保留，草稿留在页面内存。正式主岛 SQLite 和已有真实报告不受影响。
- v0.14 后，北岸同时提供「准备虚拟来客并远航」与「开发隔离」。前者使用正式聚会管线及当前配置的真实模型；后者保留显式模拟分析选项。更新页面后也必须重启运行中的试玩后台，否则新入口会返回「接口不存在」。

## 收纳后的测试控制

进入岛后左侧齿轮可打开工具：推进测试时钟、模拟到期、让下一次已携带的纳德分析失败、独立重试失败助理、检查 B 的私人收件箱、修测试船。到期停止新增消息，已接受任务继续处理固定快照；修测试船消耗的是隔离副本的 20 木料。重新创建旅程不会丢下上一段已接受的最后一批任务。
