# 邮局：用自己的邮箱发信

邮件会发给当前小岛设置的岛主收件邮箱。每位岛主可在「我的岛屿 → 资料配置」设置自己的收件地址。访客填写的回复邮箱会放在 Reply-To，岛主点击邮件中的回复即可联系访客。

发信邮箱是服务器配置，收信邮箱是岛主资料，两者可以相同也可以不同。游客不需要提供发信凭据。

## Gmail 配置

1. 为发信 Google 账户开启两步验证。
2. 打开 https://myaccount.google.com/apppasswords ，创建名为「云汀岛邮局」的应用专用密码。Google 官方说明：https://support.google.com/accounts/answer/185833?hl=zh-Hans 。账号是否支持该选项以 Google 账户页面为准。
3. 在本地 `.env` 中填写 `SMTP_PASSWORD`，去掉展示时用于分组的空格。不要使用 Google 登录密码，不要把凭据放进公开资料。
4. 重启开发服务以读取配置。

```dotenv
MAIL_PROVIDER=smtp
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=你的发信邮箱
SMTP_PASSWORD=你的应用专用密码
MAIL_FROM=你的发信邮箱
```

QQ 邮箱或其他提供 SMTP 的邮箱也可使用同一功能；改用服务商公布的 SMTP 主机、465 或 587 端口，以及 SMTP 授权码。仅接受加密连接，587 强制 STARTTLS。

## 验证完整链路

在风铃邮局生成草稿，填写回复邮箱并获取验证码。在邮箱中查看验证码并回填，然后检查收件人、主题、正文，勾选确认，点击寄出。服务商接受后，仍须到岛主邮箱确认是否入箱，必要时查看垃圾邮件。

重复点击已发送邮件不会再次发送。SMTP 连接中断时，系统保存「结果待核实」并停止重试；岛主需核对邮箱记录，防止实际已送达的邮件被重复寄出。Resend 仍保留原有请求去重重试机制。
