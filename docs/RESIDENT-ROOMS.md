# 房间里的私人汇报

游客与岛主共用同一座小岛和居民，但入口不同。进入居民住宅后先显示可行走的房间。无论居民是否在家，走到中央书桌前按 E，游客打开登记、资料补充或公开问答；通过密码确认身份后的岛主打开受保护的成果室。

户外点击居民或靠近按 E，只进行游戏生活对话，保留居民间的故事线；没有模型问答、资料提交或成果入口。各居民按岛上时间在家和外出，外出时住宅为空，书桌仍可随时查看工作资料。交谈期间暂停岛上时间与人物行走，后台资料处理不受影响。

- 档案馆：以登记的人为索引，查看背景、来访目的、登记时间、报告、原始来源与已验证联系邮箱。
- 码头：列出自愿登记记录，并统计匿名到访。匿名旅人不编造身份档案。
- 策展工坊：以阅读札记为入口，展现选出的重点与理由，能回看对应访客资料。
- 专项研究室：按项目卡片陈列；只提取原始资料中明确存在、与岛主专题相关的项目。主题未设置、没有相关项目或报告失败时如实显示。旧报告可整理为新卡片，原文保留为历史报告。
- 联络官邮局：查看交流理由与待核实问题，从项目或档案带入作者上下文。仅向访客已验证的邮箱发送；先显示可编辑主题、正文和收件人，岛主确认后才发送。

链路：项目 → 项目详情与原始引用 → 前往档案官住宅查看作者 → 前往联络官住宅 → 预览并确认邀请。跨房间的链接保留选中的访客或项目，提示去对应住宅；走到书桌前按 E 后恢复该上下文。浏览成果不会自动调用模型，也不会自动寄出邮件。后台正常登记队列及用户主动整理仍使用真实模型。

所有成果室及主动联系接口要求岛主服务端会话。新资料版本不会展示旧报告为当前项目卡片。邮件保存确认内容并避免重复提交；结果不明时阻止重试，等待核实。删除来访时清理本地邀请内容，只保留不含正文的投递审计记录。
