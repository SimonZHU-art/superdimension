# 最新访客投影：可重复体验

1. 使用新的浏览器会话或无痕窗口打开小岛，完成序章，到阿斯加德屋内书桌自愿登记。
2. 填写称呼、背景与来访目的。在“交流风格与兴趣”填入你希望使用的风格；简历中的明确偏好同样可用。例如：喜欢摄影，说话简短直接，偶尔开轻松的玩笑。不要为了测试提交不愿保存的真实资料。
3. 关闭登记窗口，角色头顶与左上角介绍应显示登记称呼；继续用 WASD 操控同一个角色，地图不额外生成一排访客。
4. 在同一窗口登录岛主。你控制 JuJu，最新登记者成为可走动的访客投影；当前登记者恰好是最新访客时，投影从刚才释放的位置开始活动。
5. 点击这个角色或靠近按 E，选择“认识一下你”，再问“你喜欢什么？”“你会怎样介绍自己？”。回答依据获准原始资料，并可展开所引用资料。交流风格不是对真实人格的保证；未提供风格时采用自然简洁的表达。
6. 用另一个无痕会话登记另一位访客。岛主刷新后，地图仅显示新的一位。之前的资料仍在档案官及私人书桌里。
7. 普通匿名刷新不会替换最新登记者。访客撤回资料后，其投影聊天记录也会删除，地图退回仍有授权资料的最新登记者。

## 自动验证

`node --test tests/visitor-projection.test.mjs` 使用临时数据库及明确标记的模拟模型，验证最近登记排序、仅一个模型、游客无法读取投影、聊天鉴权、来源与风格进入模型上下文、旧访客请求拒绝、撤回清理。模拟模型结果不代表真实语言质量。

生产不会自动插入测试人物，不会删除历史访客。投影不是实时多人连接，不替真人作出合作承诺或发送邮件。

## 本轮真实模型抽查
使用独立数据库里的虚构人物“测试旅人·小岚”，没有向正式小岛添加数据。其资料为喜欢摄影、街头光影、表达简短直接、偶尔玩笑。实际模型续聊回应：“就蹲路灯下面，等树影被风吹乱那一秒。人过去就按，糊了也算氛围。”并注明这不是已发生的真实经历。截图：`docs/proofs-v052/visitor-style-chat.png`。这一抽查证明链路与该样例可用，不保证任意资料都能精确复现真人性格。
