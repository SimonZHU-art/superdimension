# 场景可读性 · v0.8

## 视觉约束

沿用已有像素小镇，以草绿 #91ad6b、旧木 #806b4d、石灰 #c6c9b4、路石 #d8cfb6、水绿 #65a6a5、暖灯 #ffe3a2 为基色。原有中文正文与像素标牌维持一致。将细节集中到有互动的实体，每个物件有可辨识轮廓和自己的空间。

道路形成东西主路、南侧连接路与两条南北通路。整张路网先画路缘，再统一铺路面，交叉口不会被后画的边框截断。石板纹理只在路面内出现。支路连接门前平台，不穿过建筑。

花架位于广场西侧，独立的木格、立柱、陶盆与花朵。破损时横梁折断、花盆倾倒；4 木料修复原地重建，约 1.8 秒木梁升回、花盆回位，减少动画设置直接显示完成。小牌写明花架及破损状态。新旅程初始有破损花架，旧旅程保留原状态。旧树木/门饰修复事件归一到这座花架。

石井位于主路北侧，石圈、黑色井口、绞盘、垂绳、旁置木桶形成清楚轮廓。水保持在井内，没有喷泉。靠近可听三次轻敲；查看、放桶、再听形成递进悬疑，保持未解答。

晾衣架位于邮局东侧院子，双柱、支脚、绳索、衣夹、外衣、方巾、接水盆组成完整物件。潮衣客章节只有蓝衣持续滴水，其他章节干燥。原来井边悬浮的蓝布删除。衣架可观察、摸衣角、检查绳结。

银杏长椅放在东西主路北侧，座面和靠背沿路平行；路灯让出道路。玩家、场景物件、房屋和树木按脚下纵坐标排序，遮挡关系一致。

## 交互边界

修复花架仅消耗该结构的材料，不顺带治好居民、清除其他剧情痕迹。井和衣架只有观察，不收木料。观察次数按当前旅程和章节持久保存；用户资料与 AI 报告不接收这些虚构线索。所有物件实体底座有碰撞，近旁留有可到达的交互位置。
