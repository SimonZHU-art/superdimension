# v0.9 · 连续居民动作与房屋空间

居民按逐帧距离推进路线，交谈时停在当前位置，结束后继续。故事接待、护送与白天会议结束时，普通路线从最后可见位置重新衔接；不会依据旧路线的绝对时间跳回。回家走到门前后以短暂淡出进入室内。首个故事日取消岛主室外模型隐藏。漫游伙伴同样采用逐帧移动。

房屋后方有人时屋顶适度淡化，保留行走角色的可见性；日常手臂、脚步和上下起伏共享步行动画。减少动画设置仍保留必要位置移动。

档案馆、行业工坊朝东，黄四郎工坊朝西，其余建筑保留南向。侧向房屋采用侧墙、入口墙、双屋顶面、窗户、门廊与门阶，普通房屋加深侧面。碰撞实体包含侧墙；真实门口坐标用于进入、离开、NPC 回家、寻路、互动与灯光。门前支路接入主路。屋内沿用原有功能与陈设。

验收：最终 102 项完整回归全部通过，生产构建成功。新增检查交谈暂停后连续行走、回家不提前消失、各朝向门口可达与侧墙实体。隔离页面从码头自动步行进入档案馆侧门，退出后落在侧门外；截图中朱珠在连续两次观察间继续行走。正式页面已刷新加载最终客户端，隔离页面与服务已关闭。画面：docs/proofs-v09/oriented-cottages.png。
